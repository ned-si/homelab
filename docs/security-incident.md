# Credentials once committed in plaintext

Before this repository used SOPS, credentials were committed in plaintext, and
GitHub keeps those commits reachable through old pull-request refs even after
the history rewrite. Treat every value below as public. Each one has been
rotated, retired, or is tracked privately by the owner; none is reused anywhere
in the current tree. Values are referenced by file and key only.

| # | What | Where it was | Grants | Current home |
| --- | --- | --- | --- | --- |

| 2 | TrueNAS API key | same file, `driver.config.httpConnection.apiKey` | the TrueNAS API: every dataset and zvol | same sealed file |
| 3 | Cloudflare API token | `kubernetes/applications/{cert-manager,external-dns}/cf-api-token-secret.yaml` | DNS edit for `lilalala.com`, so certificates for any name | `infrastructure/secrets/cloudflare-{cert-manager,external-dns}.sops.yaml`, one token each |
| 4 | Keycloak bootstrap admin password | `kubernetes/applications/keycloak/keycloak.yaml`, `KC_BOOTSTRAP_ADMIN_PASSWORD` | admin of the identity provider, so every SSO app | `platform/secrets/keycloak-admin.sops.yaml` |

Also by omission: `PAPERLESS_SECRET_KEY` was never set, so Paperless signed
sessions with Django's public default key. It is set from
`apps/secrets/paperless-secrets.sops.yaml` now.

Six of these (rows 4 to 8) were literal values in `env:` entries or Helm values,
not `kind: Secret` objects. That shape is why `scripts/leak-check.sh` looks for
credentials as literal values anywhere Argo CD syncs, not only in Secrets.

## If one of them is found in use

Rotate it at its source with the procedure in
[secrets.md](secrets.md#rotating-a-credential), check the source's access log
for the period since publication, and record the new value in the password
manager. For the NAS (rows 1, 2 and 10) also check `root`'s `authorized_keys`
and the API key list on TrueNAS for entries you did not create. For Cloudflare
(row 3) list the zone's API tokens and recent DNS changes. For Dynadot (row 11)
regenerate the API key in the account and check the domain's DNS and transfer
settings.

## Prevention

- SOPS for every credential, with `scripts/leak-check.sh`,
  `scripts/secrets-check.sh` and `scripts/placeholder-check.sh` in CI and
  pre-commit ([secrets.md](secrets.md#checks)).
- gitleaks on every pull request; GitHub secret scanning with push protection.
- PostgreSQL passwords are generated by CloudNativePG and never exist in git.
- `.gitignore` covers keys, `.env*`, `*.tfvars`, kubeconfigs, `secrets.local.env`
  and the `.decrypted/` scratch directory.
